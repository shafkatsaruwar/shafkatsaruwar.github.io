Live Project
92% brain power used

What It Does

Resume Tailor AI takes an existing resume and a target job description, then returns a tailored resume that mirrors role terminology and improves bullet structure without inventing qualifications.

Why It Matters

Most AI resume tools overpromise and hallucinate. This one separates honest tailoring from gap analysis, so candidates can improve alignment without faking experience.

Build Notes

  • Gemini-powered tailoring engine with structured JSON output and strict no-fabrication rules.
  • Straight-talk recruiter feedback for weak bullets, stretch warnings, and missing JD requirements.
  • Resume parser that turns raw text into structured sections.
  • Live resume studio with templates, typography controls, print-to-PDF, JSON import/export, keyboard shortcuts, and dark navy mode.
  • Node/Express backend with Helmet CSP, rate limiting, Firebase Auth, Firestore, and LocalStorage autosave.
